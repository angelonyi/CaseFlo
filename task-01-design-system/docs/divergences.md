# Divergences

## 1. Font Family

- **MD3 default:** Google Sans
- **My choice:** DM Sans
- **Why I chose it:** I chose DM Sans because I like how clean and easy to read it is. Since CaseFlo is for law firms and their clients, I wanted a font that makes information easy to read.
- **When my choice might be wrong:** If users find Google Sans easier to read, then DM Sans might not be the better choice.

## 2. Display Large

- **MD3 default:** 57px font size, 400 weight, −0.25px letter spacing, 64px line height.
- **My choice:** 64px font size, 600 weight, −3.5px letter spacing, 96px line height.
- **Why I chose it:** I wanted the main heading to stand out, so I used a larger font size and a heavier weight.
- **When my choice might be wrong:** The heading might look too big on a phone screen or take up too much space if the text is long.
