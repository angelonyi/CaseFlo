# Type Scale

## Font

- **Font family:** DM Sans
- **Source:** Google Fonts
- **Why I chose it:** I chose DM Sans because it is clean and easy to read. CaseFlo is for clients who need to check their legal matters, appointments, documents, and bills. The text should be clear and easy to understand.

## Typography System

I used Google Material Design 3 as a guide when creating my typography system.

I created five text roles: Display, Headline, Title, Body, and Label. Each role has three sizes, giving me a total of 15 text styles.

## Line Height

My line-height rule is:

**Font size × 1.5 = line height**

I used this rule to give text enough space to be comfortable to read.

## Letter Spacing Test

I tested two letter-spacing options for Display Medium.

- **Default:** 0 — `evidence/03-spacing-default.png`
- **My choice:** -1 — `evidence/04-spacing-chosen.png`

With the default spacing, the letters looked too far apart. I chose tighter spacing because it looked better in my design.
