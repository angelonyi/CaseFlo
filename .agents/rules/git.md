*   **Rule:** Stage and commit your changes locally but never push to a remote repository.
*   **Reason:** A human must review and test all code before it leaves the local machine.
*   **Rule:** Make exactly one commit per requested task.
*   **Reason:** Grouping unrelated changes makes it impossible to revert mistakes cleanly.
*   **Rule:** Stay on the current working branch unless explicitly told to create a new one.
*   **Reason:** Unprompted branching fragments the workspace.
